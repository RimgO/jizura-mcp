JIZURA MCP & VIDEO STUDIO

JIZURA MCP 利用・操作ガイド

1. クイックスタート

Node.js (v18以降) および FFmpeg がインストールされた環境で使用できます。

インストール

# 依存パッケージのインストール（Playwright Chromiumも自動導入）
npm install

# TypeScriptのビルド
npm run build

WebUI（JIZURA Video Studio）の起動

npm run ui
# 起動後、ブラウザで http://localhost:3000 にアクセス

動作確認テスト

npm run verify

2. WebUI (JIZURA Video Studio) の使い方

WebUIを使うと、YouTube動画やローカル動画を直感的に読み込み、音楽とタイポグラフィを完全に同期させた動画を生成できます。

STEP 1
動画ソースの選択

YouTube URLを入力して「動画を取得」をクリックするか、「ローカル動画をアップロード」タブから手持ちのMP4/MOVファイルをドラッグ＆ドロップします。

STEP 2
タイムラインと歌詞入力

動画を再生しながら「⏱️ タイムスタンプ挿入」を押すと、再生位置のタイムコード（[00:12.50]等）が歌詞エディタに自動挿入されます。

STEP 3
スタイル & 配置の選択

「ノワール・クロマ」「ダークHUD」など好みのスタイルを選択。被写体の顔を遮らないよう「👇 下部テロップ」配置を選びます。

STEP 4
プレビュー & 書き出し

「プレビュー生成」で静止画を確認し、「動画を書き出す」を押すと、完全透過アルファ合成された完成MP4が生成・ダウンロードできます。

3. テロップ配置＆被写体避けのコツ

JIZURA本来のスタイルは画面中央に巨大な装飾プレート（パズルや矢印など）を出すものが多いため、人物やキャラクターがいる動画では以下の設定が効果的です。

💡 おすすめの設定

・配置位置: 👇 下部テロップ (推奨) を選択
・文字サイズ: 標準 (65%) または 小 (50%) に設定
・縦オフセット: スライダーで +40px 〜 +80px 程度下に下げる

巨大なパズルや矢印プレートを抑える方法

歌詞テキストに *強調歌詞*（アスタリスク）を使用すると、JIZURAは「サビの目玉演出」として画面いっぱいの巨大プレートやパズルピースを生成します。

  • スッキリ見せたい場合: アスタリスク * を外し、通常の改行や /（カット区切り）で入力します。
  • 文字を小さく控えめにしたい場合: ~ささやき歌詞~（チルダ）で囲むと、邪魔にならないスマートなフォントサイズで描画されます。

4. JIZURA 歌詞記法リファレンス

記法 効果 入力例
1行 ＝ 1フレーズ 改行ごとに次の演出カットへ切り替わります 夜明けの色を
覚えてる
/ (スラッシュ) 1行の中でさらに細かくカットを分割します 夜明けの色を / 覚えてる
*文字* (アスタリスク) サビ用・文字と演出プレートを巨大化して強調 *透明なままじゃ終われない!*
~文字~ (チルダ) Bメロや静かなパート用・控えめに小さく表示 ~ほどけた声が遠くで鳴った~
行末 ! (感嘆符) 画面揺れ（シェイク）やフラッシュ演出 走り出せ!
{ } (波括弧) 複数行を画面上に残したまま順に重ねて表示 {
一行目
二行目
}
[mm:ss.ss] LRC形式のタイムスタンプ（曲のビートと同期） [00:04.20]サビの歌詞

5. MCPクライアント（Claude等）連携

Claude DesktopなどのMCPクライアントに本サーバーを登録すると、AIアシスタントとのチャットを通じて自然言語でJIZURAを操作できます。

Claude Desktop 設定例 (claude_desktop_config.json)

{
  "mcpServers": {
    "jizura": {
      "command": "node",
      "args": ["/Users/rimgo/jizura-mcp/dist/index.js"]
    }
  }
}

指示プロンプト例

「この動画に合う歌詞を作って、JIZURAでダークHUDスタイル、サビは強調してプレビューを見せて」

「BPM 128に設定して、ノワール・クロマ風の演出で動画を書き出して」

6. 提供MCPツール一覧

ツール名 引数 説明
jizura_open headless ブラウザを起動してJIZURAを開く（初期化）
jizura_snapshot なし 画面上のボタン／チェックボックス／入力欄一覧を取得
jizura_set_lyrics lyrics 記法済みの歌詞テキストを流し込む
jizura_click buttonName 表示ラベル名でボタンをクリック（例: おまかせで作る）
jizura_set_checkbox label, checked チェックボックスのON/OFF（例: アイテム枠表示）
jizura_fill label, value テキスト入力欄への入力（曲名、アーティスト、BPM等）
jizura_screenshot なし 現在のプレビュー画面をBase64 PNGで取得
jizura_export buttonName, savePath MP4または透過PNG(ZIP)を書き出してローカル保存
jizura_close なし ブラウザを終了してリソースを解放

7. トラブルシューティング

動画の背景が白く塗りつぶされ、文字の中にだけ動画が見える場合

旧方式のカラーキー（色抜き）合成が使われている可能性があります。最新版ではJIZURA公式の「透過PNG（ZIP・背景なし）」とFFmpegアルファオーバーレイにより完全解決されています。npm run ui を再起動し、最新版でお試しください。

動画の再生や書き出しでタイムアウトする場合

FFmpegがシステムにインストールされているか確認してください（ffmpeg -version）。macOSの場合は brew install ffmpeg yt-dlp で導入できます。
